# Vehicle brand logo assets

The storefront uses each `car_brands.logo_url` value returned by the API; components do not map manufacturer names to local files. The corresponding PNGs live at `apps/web/public/manufacturers/<slug>/logo.png`, and the live brand/model rows point to `/manufacturers/<slug>/logo.png`.

| Manufacturer | Source and variant |
|---|---|
| BMW | [BMW.svg on Wikimedia Commons](https://commons.wikimedia.org/wiki/File:BMW.svg), attributed to BMW; this is the historic vehicle-roundel version identified as 1997–2020. |
| Chevrolet | [Chevrolet bowtie 2023 SVG](https://commons.wikimedia.org/wiki/File:Chevrolet_bowtie_2023.svg), with Chevrolet’s official site listed as source. |
| Ford | [Ford flat logo SVG](https://commons.wikimedia.org/wiki/File:Ford_logo_flat.svg), attributed to Ford Motor Company and sourced from its 2017 Annual Report. |
| Honda | [Honda refreshed H mark](https://commons.wikimedia.org/wiki/File:Honda_new_h_mark.svg), citing Honda Motor Co. and its newsroom; used from 2026. |
| Hyundai | [Hyundai Motor Company logo](https://commons.wikimedia.org/wiki/File:Hyundai_Motor_Company_logo.svg), attributed to Hyundai Motor Company. |
| Kia | Original black/RGB digital PNG from Kia’s [official Brand Logo package](https://worldwide.kia.com/en/brand/our-brand/brand-elements/brand-logo-story); Kia says the current mark has been used since 2021. |
